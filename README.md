<h1 align="center">Omarchy-Podcast</h1>
<p align="center">A native podcast player for <a href="https://omarchy.org">Omarchy</a>: a bar widget, a now-playing dropdown, and a launcher-style library window.</p>

> Work in progress. Install and usage notes land with the first release.

## Development

```bash
git clone https://github.com/hominluo/Omarchy-Podcast ~/.config/omarchy/plugins/io.github.hominluo.podcast
omarchy plugin enable io.github.hominluo.podcast --section right --before omarchy.audio
omarchy restart shell
./check
```
